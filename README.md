# Student Management App - Flask + SQLite + Docker

A simple Flask web app to add and manage student records. Data is stored in SQLite.

## 🚀 Tech Stack
- Python, Flask
- SQLite (students.db)
- Docker (optional)

## 📂 Features
- Add student: Name, Email, Course
- View all students
- Lightweight & beginner friendly

## ▶️ How to Run Locally
```bash
pip install -r requirements.txt
python app.py
